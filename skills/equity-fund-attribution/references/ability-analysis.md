# 基金经理能力圈分析框架

> 基于海通证券能力圈分析体系，将归因结果转化为对基金经理投资能力的定性评估。

## 分析原则

**核心顺序**：先分析基金经理的偏好，再针对偏好分析其能力。

即先确定"他做什么"（投资方法论、风格倾向），再评估"做得好不好"（各维度能力的量化表现）。

---

## 模块一：投资方法分类

### 分类维度

| 维度 | 类型A | 类型B | 判断依据 |
|------|-------|-------|---------|
| 决策方向 | 自下而上（选股驱动） | 自上而下（配置驱动） | Brinson中SS vs AA的相对大小 |
| 投资哲学 | 价值投资 | 成长投资 | HML因子暴露长期方向 |
| 决策方式 | 量化驱动 | 主观判断 | 换手率稳定性、持仓集中度模式 |
| 持仓周期 | 短线交易 | 长线持有 | 换手率水平 |

### 判断方法

1. **Brinson归因**：AA（配置效应）占比高 → 自上而下型；SS（选股效应）占比高 → 自下而上型
2. **因子暴露稳定性**：暴露波动小 → 纪律化/量化驱动；波动大 → 主观择时型
3. **持仓集中度**：前十大重仓占比>60% → 集中型；<40% → 分散型
4. **行业集中度**：前三行业占比>50% → 行业聚焦型

## 模块二：资产配置能力

### 评估维度

| 指标 | 计算方式 | 评价标准 |
|------|---------|---------|
| 大类配置贡献 | Brinson AA | AA>0且持续为正=配置能力强 |
| 仓位调整灵活性 | 股票仓位变化幅度×与市场的相关性 | 降仓时点对应市场下跌=灵活 |
| 股债轮动准确性 | 股票仓位变化方向与股债相对收益的相关系数 | 相关系数>0.5=判断准确 |
| 择时贡献 | T-M/H-M择时收益 | 择时收益为正=仓位管理有效 |

### 关键问题

- 基金经理是否进行主动的仓位管理？
- 仓位调整是顺周期（追涨杀跌）还是逆周期（高抛低吸）？
- 配置决策是否创造了正收益？

## 模块三：风格分析

### 二维风格标签

```
         价值 ←————→ 成长
大盘    [大盘价值]    [大盘成长]
中盘    [中盘价值]    [中盘成长]
小盘    [小盘价值]    [小盘成长]
```

判断依据：
- 市值维度：HML中的Size因子（SMB）长期暴露方向
- 风格维度：HML因子长期暴露方向

### 三维风格标签（加动量）

在二维基础上增加动量/反转维度：
- MOM因子暴露>0 → 趋势跟随型
- MOM因子暴露<0 → 逆向投资型

### 风格稳定性监测

通过滚动回归跟踪因子暴露变化：

| 状态 | 表现 | 评价 |
|------|------|------|
| 风格稳定 | 因子暴露均值稳定、波动小 | 风格清晰，可预测 |
| 风格轮动 | 因子暴露趋势性变化 | 主动择时风格，需评估择时能力 |
| 风格漂移 | 因子暴露突变、方向不一致 | 风格混乱，风险较大 |

## 模块四：行业配置能力

### 行业集中度

$$HHI_{industry} = \sum_{i=1}^{n} w_i^2$$

- HHI > 0.25 → 高度集中（前三行业占比>50%）
- HHI 0.15-0.25 → 适度集中
- HHI < 0.15 → 分散配置

**注意**：高集中度可能反映风格暴露过大，业绩可持续性差。

### 行业轮动能力

计算行业权重变化方向与行业收益排名的相关性：
$$Corr(\Delta W_{industry}, R_{industry, next\_period})$$

- 相关系数 > 0 且显著 → 具备行业轮动能力
- 相关系数 < 0 → 行业选择可能为负贡献

### 行业选择效应

通过Brinson的行业维度分解：
- 各行业配置收益贡献求和 → 总行业配置效应
- 正贡献行业数 vs 负贡献行业数 → 判断行业选择的广度

## 模块五：选股能力

### 多指标综合评估

| 指标 | 来源 | 权重建议 |
|------|------|---------|
| Carhart Alpha | 多因子回归 | 高（剔除风格后的纯Alpha） |
| Brinson选股效应(SS) | 持仓归因 | 高（直接度量） |
| Barra特质收益 | 因子模型 | 高（最精细的选股Alpha） |
| Jensen's Alpha | CAPM回归 | 中（未剔除风格） |
| Alpha稳定性 | 滚动Alpha的正值比例 | 中（持续性） |

### 选股能力的来源区分

- **选对Beta型股票**：因行业/风格因素带来的收益，可持续性较低
- **选对Alpha型股票**：剔除行业和风格后的纯个股Alpha，可持续性高

判断方法：比较Brinson SS和Barra特质收益的差异。差异大说明选股收益主要来自行业内的相对排名；差异小说明确实选到了Alpha型个股。

### 选股稳定性

- 滚动Alpha中正值占比 > 70% → 选股能力稳定
- 正值占比 50-70% → 选股能力一般
- 正值占比 < 50% → 选股能力不足或依赖运气

## 模块六：交易能力

### 交易收益贡献

将基金收益分解为：
```
总收益 = 配置收益 + 选股收益 + 交易收益
```

交易收益 = 实际持仓收益 - 假设不调仓的买入持有收益

- 交易收益 > 0 且稳定 → 具备交易能力（择机买卖）
- 交易收益 < 0 → 交易行为可能损害收益

### 换手率分析

| 换手率水平 | 含义 | 配合判断 |
|-----------|------|---------|
| 高换手 + 高交易收益 | 频繁交易且获利 | 强交易能力 |
| 高换手 + 低/负交易收益 | 频繁交易但不获利 | 过度交易 |
| 低换手 + 高Alpha | 少交易但选股准 | 强选股能力 |
| 低换手 + 低Alpha | 少交易且无超额 | 被动管理或能力不足 |

### 不同归因周期的交易收益

不同归因周期下交易收益贡献度可能不同：
- 月度归因中的交易收益 → 反映短期交易能力
- 季度归因中的交易收益 → 反映中期调仓能力
- 年度归因中的交易收益 → 可能包含了更多的策略调整信息

### 止盈止损纪律

通过持仓变动与个股涨跌的关系判断：
- 上涨时减仓 → 有止盈纪律
- 下跌时止损 → 有风控意识
- 下跌时加仓且后续反弹 → 逆向投资能力

## 其他特征

### 集中度分析

- 前十大重仓股占净值比
- 前五大行业占净值比
- 单一风格暴露度

### 组合构建方法

- **均衡配置**：各维度均匀分布
- **核心-卫星**：核心持仓（稳定）+ 卫星仓位（灵活调整）
- **集中押注**：高集中度，赌方向

### 基金经理个人特征

- 从业年限（经历牛熊周期数）
- 管理规模（规模敏感性）
- 基金公司投研支持（平台型vs个人英雄）

### 规模敏感性

分析基金规模增长后业绩是否下降：
- 规模增长后Alpha不变 → 策略容量大
- 规模增长后Alpha下降 → 策略容量有限，需关注
