# 权益类基金归因方法论详细参考

## 选股-择时能力模型

### T-M模型（Treynor-Mazuy, 1966）

$$R_p - R_f = \alpha + \beta_1(R_m - R_f) + \beta_2(R_m - R_f)^2 + \epsilon_p$$

**选股能力判断**：α > 0 且统计显著 → 基金经理具备选股能力，即在剔除系统性风险后仍能获得超额收益。

**择时能力判断**：β₂ > 0 且统计显著 → 基金经理具备择时能力。
- 经济直觉：当市场上涨时 $(R_m - R_f)$ 为大正数，基金的Beta增加（向上凸曲线），放大上涨收益；当市场下跌时 $(R_m - R_f)$ 为大负数，基金的Beta减小，控制回撤。
- β₂ < 0 → 反向择时（追涨杀跌），择时能力为负。

### H-M模型（Henriksson-Merton, 1981）

$$R_p - R_f = \alpha + \beta_1(R_m - R_f) + \beta_2 \cdot D \cdot (R_m - R_f) + \epsilon_p$$

其中 $D$ 为虚拟变量：当 $R_m > R_f$（牛市）时 $D=1$，否则 $D=0$。

**择时判断**：β₂ > 0 且显著 → 牛市中Beta = β₁+β₂（加仓），熊市中Beta = β₁（减仓）。

**与T-M的区别**：H-M用分段线性模拟择时行为，T-M用二次曲线。H-M更直观地模拟"牛市加仓、熊市减仓"的决策模式。

### C-L模型（Chang-Lewellen, 1984）

$$R_p - R_f = \alpha + \beta_1(R_m - R_f) + \beta_2[(R_m - R_f) \cdot D] + \epsilon_p$$

其中 $D$ 同样为牛市虚拟变量。

**择时判断**：与T-M/H-M不同，C-L要求 **β₁ - β₂ > 0** 且越大越好。
- β₁ 代表熊市中的Beta（基础风险暴露）
- β₁ + β₂ 代表牛市中的Beta
- 择时有效意味着基金经理在牛市中降低Beta（反向逻辑，即降低市场敏感度以获得Alpha）

### 三模型判断标准汇总

| 模型 | 择时指标 | 择时有效条件 | 选股指标 |
|------|---------|------------|---------|
| T-M | β₂（二次项系数） | β₂ > 0 且 p < 0.1 | α（截距） |
| H-M | β₂（交互项系数） | β₂ > 0 且 p < 0.1 | α（截距） |
| C-L | β₁ - β₂ | β₁ - β₂ > 0 且越大越好 | α（截距） |

## 多因子模型

### Fama-French三因子模型（1993）

$$R_i - R_f = \alpha + \beta_{mkt}(R_m - R_f) + \beta_{smb} \cdot SMB + \beta_{hml} \cdot HML + \epsilon_i$$

| 因子 | 全称 | 含义 | 构建方式 |
|------|------|------|---------|
| Market | 市场因子 | 市场整体收益 | 全市场加权组合 - 无风险利率 |
| SMB | Small Minus Big | 规模因子 | 小市值组合 - 大市值组合 |
| HML | High Minus Low | 价值因子 | 高BP组合 - 低BP组合 |

**解释**：
- β_smb > 0 → 偏好小盘股
- β_hml > 0 → 偏好价值股（低估值）
- α 为剔除三种因子后的超额收益

### Carhart四因子模型（1997）

$$R_i - R_f = \alpha + \beta_{mkt}(R_m - R_f) + \beta_{smb} \cdot SMB + \beta_{hml} \cdot HML + \beta_{mom} \cdot MOM + \epsilon_i$$

新增 **MOM（动量因子）**：过去12个月赢家组合收益 - 输家组合收益。
- β_mom > 0 → 趋势跟随策略
- β_mom < 0 → 反转/逆向策略

**业界应用最广**，模型拟合优度R²>0.7的基金占比约68%。

### Fama-French五因子模型（2015）

$$R_i - R_f = \alpha + \beta_{mkt}(R_m - R_f) + \beta_{smb} \cdot SMB + \beta_{hml} \cdot HML + \beta_{rmw} \cdot RMW + \beta_{cma} \cdot CMA + \epsilon_i$$

| 因子 | 全称 | 含义 |
|------|------|------|
| RMW | Robust Minus Weak | 盈利因子：高盈利公司 - 低盈利公司 |
| CMA | Conservative Minus Aggressive | 投资因子：保守投资公司 - 激进投资公司 |

对收益的解释力度进一步提升，但对A股适用性需要验证（A股盈利因子表现与美股不同）。

### 其他进阶模型

- **Novy-Marx四因子（2013）**：关注毛利等盈利质量因子
- **Hou-Xue-Zhang四因子（2015）**：基于q-factor模型（市场、规模、投资、盈利）
- **Daniel-Hirshleifer-Sun三因子（2020）**：考虑长/短周期行为因子

### A股因子数据获取

| 因子 | 数据源 | 构建方式 |
|------|--------|---------|
| Market | Wind/聚宽 | 沪深300或中证800超额收益 |
| SMB/HML | CSMAR/聚宽 | 按市值和BP排序构建 |
| MOM | 自行构建 | 过去12月收益减过去1月收益 |
| RMW/CMA | 自行构建 | 按ROE和投资率排序 |

## Brinson持仓归因

### 基本框架

$$R_P - R_B = \sum_{i=1}^{n} AA_i + \sum_{i=1}^{n} SS_i + \sum_{i=1}^{n} IA_i$$

其中：
- $AA_i = (W_{pi} - W_{bi}) \times R_{bi}$（资产配置效应）
- $SS_i = W_{bi} \times (R_{pi} - R_{bi})$（选股效应）
- $IA_i = (W_{pi} - W_{bi}) \times (R_{pi} - R_{bi})$（交互效应）

### BHB方案 vs BF方案

| 方案 | 交互效应处理 | 特点 |
|------|------------|------|
| BHB | 单独列示或归入选股 | 经典原始方案 |
| BF | 归入配置效应 | 配合GRAP算法效果更优 |

### 多期Brinson联结

**GRAP算法**（Geometric Return Attribution）：
$$R_{P,total} = \prod_{t=1}^{T}(1+R_{Pt}) - 1$$
归因更清晰可靠，修正了简单加总的再投资问题。

**Carino联结**（无残差）：
引入平滑因子 $a_t = \frac{R_{Pt} - R_{Bt}}{\ln(1+R_{Pt}) - \ln(1+R_{Bt})}$，将各期残差重新分配。

**Menchero联结**（无残差）：
试图保持原始归因项的相对重要性。

### 不同基金类型的应用

- **股票型基金**：在各行业上分解选择收益和配置收益
- **偏股混合型基金**：在各大类资产（股票/债券/现金）上分解
- **持仓补全技术**：利用基金季报补全持仓，行业主行业选股R²可达0.84-0.98

## CT&CS风格绩效归因

海通证券提出的风格归因模型，将Brinson思路应用于风格维度：

| 成分 | 英文 | 含义 |
|------|------|------|
| AS | Allocation on Style | 被动风格暴露带来的收益（市值、价值等因子的Beta收益） |
| CT | Concentration on Timing | 基金经理主动调整风格暴露带来的择时收益 |
| CS | Concentration on Selection | 在特定风格内精选个股带来的选股收益 |

**关键发现**：短期而言，AS（被动风格收益）是主动权益基金最重要的收益来源，这意味着很多基金经理的"Alpha"实际上来自风格Beta。

## Barra多因子风险模型

### 模型框架

$$R_i = \sum_{k=1}^{K} X_{ik} \cdot f_k + \epsilon_i$$

其中 $X_{ik}$ 为股票 $i$ 对因子 $k$ 的暴露度，$f_k$ 为因子 $k$ 的收益，$\epsilon_i$ 为特质收益。

### 因子体系（以CNE5为例）

Barra模型通常包含39个风险因子：
- **国家因子**（1个）
- **行业因子**（约30个，按申万/中信行业分类）
- **风格因子**（约10个）：
  - Size（市值）：对数市值
  - Beta：市场Beta
  - Momentum（动量）：相对强弱
  - Residual Volatility（残差波动）：剔除市场后的波动
  - Non-linear Size（非线性市值）：中盘因子
  - Book-to-Price（账面市值比）
  - Liquidity（流动性）
  - Earnings Yield（盈利收益率）
  - Growth（成长性）
  - Leverage（杠杆）

### 与净值法的本质区别

| 维度 | 净值法（RBA） | Barra（HBA） |
|------|-------------|-------------|
| 因子暴露获取 | 时间序列回归估计 | 个股暴露加总计算 |
| 更新频率 | 每日 | 持仓时点 |
| 因子维度 | 4-5个 | 30+个 |
| 精度 | 较粗 | 最精细 |

### 收益分解

$$R_p = \underbrace{\sum_k X_{pk} f_k}_{\text{共同因子收益}} + \underbrace{\sum_i w_i \epsilon_i}_{\text{特质收益}}$$

- 共同因子收益 → 反映基金经理的**风格选择能力**
- 特质收益（残差）→ 反映基金经理的**真实选股Alpha**

业界总结："始于Brinson，归于Barra"——先以Brinson做初步归因（配置vs选股），再以Barra做精细化因子级归因。

## 风险归因

### x-sigma-rho三要素法

$$RC_k = X_k \times \sigma_k \times \rho_k$$

| 要素 | 含义 | 分析价值 |
|------|------|---------|
| X（因子暴露） | 组合在因子k上的暴露度 | 主动承担了多少风险 |
| σ（因子波动率） | 因子k自身的波动率 | 因子本身的风险大小 |
| ρ（因子-组合相关性） | 因子k收益与组合收益的相关系数 | 因子与组合的联动程度 |

三个维度的乘积给出因子k对组合总风险的贡献。

### 单一波动分解

将组合总波动率按因子分配：
$$\sigma_p^2 = \sum_k \sum_j w_k w_j \sigma_{kj}$$

### 边际风险分解

$$MRC_k = \frac{\partial \sigma_p}{\partial w_k}$$

衡量权重微调对组合总风险的边际影响，用于优化仓位和判断调仓方向。

## 回归执行注意事项

### 滚动窗口选择

| 窗口 | 适用场景 |
|------|---------|
| 24个月 | 捕捉近期风格变化 |
| 36个月 | 平衡稳定性与及时性 |
| 60个月 | 长期风格特征分析 |

### 多重共线性处理

- 因子间VIF（方差膨胀因子）>10 时存在严重共线性
- 解决方案：PCA降维、逐步回归、Lasso正则化

### 风格漂移检测

通过滚动回归跟踪因子暴露变化：
- 暴露波动度小 → 风格稳定
- 暴露趋势性变化 → 风格漂移
- 暴露突变 → 可能更换了投资策略

### 统计显著性标准

| 指标 | 显著水平 | 含义 |
|------|---------|------|
| p < 0.01 | 高度显著 | 99%置信度下不为零 |
| p < 0.05 | 显著 | 95%置信度 |
| p < 0.10 | 边缘显著 | 90%置信度，择时检验常用 |
| p ≥ 0.10 | 不显著 | 不能排除随机性 |

### 归因周期建议

- 1年以下：参考价值有限，统计噪声大
- 1-3年：可作为初步判断
- 3年以上：归因结论具有统计意义
- 跨越牛熊周期（5-7年）：最可靠的能力评估
