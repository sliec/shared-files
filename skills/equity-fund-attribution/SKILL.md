## 三大归因路径总览

| 路径 | 核心方法 | 数据需求 | 更新频率 | 归因精度 |
|------|---------|---------|---------|---------|
| **净值法(RBA)** | 时间序列回归 | 净值序列 | 每日 | 较粗（因子层面） |
| **持仓法(HBA)** | Brinson/CT&CS/Barra | 持仓明细 | 每季度 | 精细（行业+个股） |
| **风险归因** | 因子风险分解 | 持仓+因子库 | 持仓时点 | 最精细 |

**专业建议**：三种方法结合使用，多角度互相验证。

## 路径一：净值法归因（RBA）

### 基础层：风险调整绩效指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 夏普比率 | (Rp-Rf)/σp | 单位总风险的超额回报 |
| 特雷诺比率 | (Rp-Rf)/βp | 单位系统性风险的超额回报 |
| 詹森Alpha | α = Rp-[Rf+β(Rm-Rf)] | CAPM截距，跑赢市场风险预期 |
| 信息比率 | (Rp-Rb)/TE | 单位跟踪误差的超额收益 |

### 进阶层：选股-择时能力模型

**T-M模型**（Treynor-Mazuy, 1966）：
```
Rp-Rf = α + β₁(Rm-Rf) + β₂(Rm-Rf)² + ε
```
- α>0 → 选股能力；β₂>0且显著 → 择时能力

**H-M模型**（Henriksson-Merton, 1981）：
```
Rp-Rf = α + β₁(Rm-Rf) + β₂·D·(Rm-Rf) + ε  [D=1 if Rm>Rf else 0]
```
- β₂>0且显著 → 牛市加仓/熊市减仓

**C-L模型**（Chang-Lewellen, 1984）：
```
Rp-Rf = α + β₁(Rm-Rf) + β₂[(Rm-Rf)·D] + ε
```
- β₁-β₂>0且越大 → 择时能力越强

### 核心进阶：多因子模型

| 模型 | 因子 | 适用场景 |
|------|------|---------|
| Fama-French三因子 | Market + SMB + HML | 规模+价值风格分析 |
| Carhart四因子 | + MOM | 最常用，加动量维度 |
| Fama-French五因子 | + RMW + CMA | 加盈利+投资因子 |

**关键技能要点**：
- 滚动窗口：通常24-60个月
- 风格漂移检测：跟踪因子暴露的时序变化
- 多重共线性：因子间相关性可能导致估计失真
- R²>0.7的基金占比约68%（Carhart模型）

详细公式见 [references/methodology.md](references/methodology.md)

## 路径二：持仓法归因（HBA）

### Brinson模型

将超额收益分解为三项：

| 归因项 | 公式 | 含义 |
|--------|------|------|
| 配置效应(AA) | (Wpi-Wbi)×Rbi | 行业/板块权重偏离的贡献 |
| 选股效应(SS) | Wbi×(Rpi-Rbi) | 行业内的个股选择能力 |
| 交互效应(IA) | (Wpi-Wbi)×(Rpi-Rbi) | 配置与选股的交叉作用 |

**BHB vs BF方案**：BHB单独列示交互效应；BF将交互归入配置，配合GRAP算法效果更优。

**多期Brinson**：GRAP算法修正再投资问题，Carino/Menchero无残差联结。

**持仓补全技术**：季报补全持仓做归因，行业选股R²可达0.84-0.98。

### CT&CS风格归因（海通证券）

| 成分 | 含义 |
|------|------|
| AS（风格收益） | 被动风格暴露带来的收益 |
| CT（风格择时） | 主动调整风格暴露的收益 |
| CS（风格选股） | 特定风格内的选股收益 |

研究发现：短期内AS是主动权益基金最重要的收益来源。

### Barra多因子归因

```
组合收益 = Σ(因子暴露 × 因子收益) + 特质收益
```

- 共同因子收益 → 风格选择能力
- 特质收益（残差）→ 真实选股能力

**与净值法的本质区别**：因子暴露通过个股暴露加总获得，而非回归估计。

业界总结："始于Brinson，归于Barra"。

## 路径三：风险归因

| 方法 | 原理 | 用途 |
|------|------|------|
| 单一波动分解 | 将总风险按因子分配 | 快速判断主要风险因子 |
| 边际风险分解 | 权重微调对总风险的边际影响 | 优化仓位/调仓方向 |
| x-sigma-rho法 | 风险贡献=暴露×波动率×相关性 | 三维度精细识别 |

## 基金经理能力圈分析

归因结果需结合能力圈六模块进行定性评估。详细框架见 [references/ability-analysis.md](references/ability-analysis.md)。

**六模块速览**：

1. **投资方法分类**：自下而上vs自上而下、价值vs成长、量化vs主观
2. **资产配置能力**：大类配置贡献、仓位灵活性、股债轮动判断
3. **风格分析**：二维（市值×风格）+ 三维（加动量）标签，稳定性监测
4. **行业配置能力**：集中度、轮动能力、选择效应
5. **选股能力**：Alpha稳定性、选beta型vs alpha型股票
6. **交易能力**：换手率-收益关系、止盈止损纪律

**分析顺序**：先分析基金经理的偏好，再针对偏好分析其能力。

## 量化分析工作流

### 步骤1：数据准备

| 数据类型 | 来源 | 频率 |
|---------|------|------|
| 基金净值 | Wind/聚宽/天天基金 | 日 |
| 基金持仓 | 季报/半年报/年报 | 季 |
| 基准指数 | 沪深300/中证500/中证800 | 日 |
| 因子数据 | CSMAR/聚宽/优矿 | 日/月 |
| 行业收益 | Wind行业指数 | 日 |

### 步骤2：选择归因路径

```
有持仓数据？
├── 是 → Brinson行业归因 + Barra因子归因（深度分析）
└── 否 → 多因子回归 + 择时检验（快速扫描）
```

### 步骤3：执行计算

脚本支持以下子命令：
- `factor` — 多因子回归（CAPM/FF3/Carhart/FF5）
- `timing` — 择时检验（T-M/H-M/C-L三模型）
- `brinson` — Brinson行业归因
- `risk` — 风险收益全套指标
- `risk-attr` — 风险归因（x-sigma-rho）
- `ability` — 能力圈综合评级

### 步骤4：结果解读

整合视图应包含：
1. 因子暴露雷达图 + 滚动Alpha时序图
2. Brinson归因饼图（AA/SS/IA）
3. 择时检验结果汇总表
4. 回撤曲线 + 风险归因瀑布图
5. 能力圈六维雷达图

```

   2.2 多因子回归（Carhart四因子为主）
   2.3 选股-择时能力（T-M/H-M）
```

- 论述文体，不用Q&A格式
- 公式用LaTeX行内（$..$）
- 数据标注来源和时间区间
- 结论须量化支撑
- 3年以上的归因才有统计意义
- 定量结论 + 定性洞察交叉验证

## 基金经理评价模式

### 综合评级框架

| 维度 | 度量方法 | 评判标准 |
|------|---------|---------|
| 选股能力 | Carhart Alpha + Brinson SS + Barra特质收益 | α>0且p<0.05为优秀 |
| 择时能力 | T-M β₂ + H-M β₂ + C-L β₁-β₂ | 两个模型均显著为优秀 |
| 风格稳定 | 滚动因子暴露波动度 | 波动小=风格清晰 |
| 行业配置 | 行业轮动收益 + 集中度 | 轮动正贡献+适度集中 |
| 交易能力 | 换手率-收益相关性 | 高换手+高交易收益=强交易能力 |
| 风控能力 | 最大回撤 + 下行标准差 + Sortino | 回撤<同类中位数为优 |

## 常见误区与注意事项

- **幸存者偏差**：只分析存续基金会高估整体表现
- **风格漂移**：固定窗口回归可能产生偏误，需滚动检测
- **持仓滞后**：季报仅反映季末时点，期间可能已大幅调仓
- **因子共线性**：部分因子高度相关，导致系数不稳定
- **Alpha vs Luck**：必须做统计显著性检验（t值）
- **短期归因无意义**：3年以上的业绩归因才有统计意义
- **定量+定性**：能力圈标签需及时更新，不能长期套用
