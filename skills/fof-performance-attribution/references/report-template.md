## 撰写规范

### 数据呈现

- 所有百分比保留两位小数（如 12.35%）
- p值保留三位小数（如 0.032）
- 金额单位统一（万元或亿元）
- 对比数据必须同期同口径

### 图表要求

每份报告至少包含：
1. **净值走势对比图**：FOF vs 基准累计净值
2. **Brinson归因饼图**：AA/SS/IA占比
3. **因子暴露雷达图**：四个因子维度的暴露度
4. **滚动Alpha时序图**：6个月或12个月滚动窗口
5. **回撤曲线图**：历史回撤深度

### 语言风格

- 以论述文体撰写，段落连贯
- 避免口语化表达
- 每个结论配具体数据支撑
- 不确定结论用"可能"、"倾向于"等措辞
- 标注数据来源和时间区间
