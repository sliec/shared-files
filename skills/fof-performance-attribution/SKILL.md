## 模式一：分析计算模式

### 输入要求

用 AskUserQuestion 收集以下信息（按需）：

1. **数据文件**：FOF净值序列（日/周频）、持仓明细（季报/半年报）、业绩比较基准构成
2. **分析期**：起止日期
3. **分析深度**：快速扫描（仅净值回归） / 标准归因（Brinson+回归） / 深度分析（含Barra穿透+择时检验）

### 计算流程

#### 步骤1：数据预处理

```python
# 读取数据并清洗
import pandas as pd
import numpy as np

# 净值序列 → 收益率序列
nav = pd.read_csv("nav.csv", index_col="date", parse_dates=True)
returns = nav.pct_change().dropna()

# 对齐频率（日→周降采样）
weekly_returns = returns.resample("W").apply(lambda x: (1+x).prod()-1)
```

- 缺失值处理：前值填充或均值填充
- 频率对齐：所有序列统一为周频或月频
- 无风险利率：默认用Shibor或1年期国债收益率

#### 步骤2：Brinson归因（需持仓数据）

将超额收益分解为三项：

| 归因项 | 公式 | 含义 |
|--------|------|------|
| 资产配置效应(AA) | Σ(Wpi-Wbi)×Rbi | 大类资产权重偏离的贡献 |
| 基金选择效应(SS) | ΣWbi×(Rpi-Rbi) | 同类内选基的贡献 |
| 交互效应(IA) | Σ(Wpi-Wbi)×(Rpi-Rbi) | 配置与选基的协同 |

FOF场景特殊适配：
- "资产配置"可扩展为：大类资产层 + 投资风格层 + 投资策略层
- "证券选择"转化为"基金选择"（Fund Selection）
- 多期使用 Carino 或 Menchero 算法联结

详细公式和计算见 [references/methodology.md](references/methodology.md) §Brinson模型。

计算脚本：`python scripts/fof_attribution.py brinson --input holdings.xlsx --benchmark benchmark.xlsx`

#### 步骤3：多因子回归（仅需净值）

依次运行三个模型，由简到繁：

```
1. CAPM回归：R_p - R_f = α + β(R_m - R_f) + ε
2. Fama-French三因子：+ β₂SMB + β₃HML
3. Carhart四因子：+ β₄MOM
```

输出：α（年化）、各β系数、t统计量、p值、R²

A股因子数据源：
- 市场因子(Rm-Rf)：沪深300或中证800超额收益
- SMB/HML：从CSMAR或Wind获取Fama-French中国三因子
- MOM：过去12个月收益减过去1个月收益

#### 步骤4：择时能力检验

**T-M模型**（Treynor-Mazuy）：
```
R_p - R_f = α + b(R_m - R_f) + c(R_m - R_f)² + ε
```
- c > 0 且显著 → 具备择时能力
- α 为剔除择时后的纯选股/选基能力

**H-M模型**（Henriksson-Merton）：
```
R_p - R_f = α + b(R_m - R_f) + d·D·(R_m - R_f) + ε
D = 1 if R_m > R_f else 0
```
- d > 0 且显著 → 牛市加仓、熊市减仓

#### 步骤5：风险收益指标

| 指标 | 公式 | 用途 |
|------|------|------|
| 夏普比率 | (Rp-Rf)/σp | 单位总风险的超额回报 |
| 最大回撤 | max((peak-trough)/peak) | 极端风险 |
| 卡玛比率 | 年化收益/max回撤 | 回撤控制能力 |
| 索提诺比率 | (Rp-Rf)/σd | 下行风险调整 |
| 信息比率 | α/ω(跟踪误差) | Alpha稳定性 |
| Calmar比率 | 同卡玛比率 | 别名 |

### 输出格式

生成结构化结果表 + 可视化图表：
1. Brinson归因饼图（AA/SS/IA占比）
2. 因子暴露雷达图
3. 滚动Alpha时序图（6个月滚动窗口）
4. 回撤曲线图
5. 择时检验结果汇总表

- 定量结论 + 定性洞察

## 模式三：投资决策辅助模式

### 评估框架

对给定FOF执行以下评估并生成能力画像：

#### 1. 收益来源解构

运行Brinson或因子回归，回答：
- 超额收益主要来自配置还是选基？
- 收益是Alpha驱动还是Beta驱动？
- 收益来源是否可持续？

#### 2. 基金经理能力画像

| 能力维度 | 度量方法 | 评判标准 |
|---------|---------|---------|
| 选基能力 | Carhart Alpha + Brinson SS | α>0且p<0.05为优秀 |
| 择时能力 | T-M系数c + H-M系数d | c>0或d>0且p<0.1为有效 |
| 风控能力 | 最大回撤 + 卡玛比率 | 回撤<同类中位数为优 |
| 风格稳定性 | 滚动因子暴露波动度 | 波动小=风格清晰 |
| 逆境表现 | 熊市期间Alpha + 回撤控制 | 下行Alpha不显著为负 |

#### 3. 综合评级

输出五级评价：卓越 / 优秀 / 合格 / 待观察 / 不建议

每个维度给出星级（1-5星）和一句话点评。

## 注意事项

- 单一模型有盲区：Brinson + 多因子回归交叉验证才能形成可信结论
- 回归只揭示相关性，非因果性：FOF的价值因子暴露可能是主动配置也可能是被动结果
- Alpha是残差项：包含了未建模的风格暴露和运气，不能简单等同于能力
- 择时模型假设基金经理能预判市场，实际中择时成功的概率历史上低于50%
- 基准选择错误会导致所有归因结论失效：分析前必须验证基准的合理性（SAMURAI原则）
- FOF的"资产配置"概念比传统基金更广：包含资产类别、投资风格、策略类型三个层次
