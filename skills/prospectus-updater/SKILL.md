# 招募说明书更新器

输入基金名称 → 自动查找代码 → 下载相关PDF → 提取数据 → 拼接输出更新后的招募说明书第八、九章。

## 工作流程

### 第一步：查找基金代码和最新报告

使用 `mx-ds-mcp` 的 `mx_finance_search_notice` 搜索基金名称，获取：
- 基金代码（如008628）
- 最新季报PDF链接（用于投资组合报告+累计净值图）
- 最新年报PDF链接（用于年度业绩数据）
- 上次招募说明书PDF链接（用于历史年度数据）

搜索关键词示例：`"基金名称 定期报告"` 或 `"基金名称 招募说明书"`

### 第二步：下载PDF

下载以下三份文件到工作目录：
1. **上次招募说明书** → 提取"九 基金业绩"年度表（2020-最新期）
2. **最新年报** → 提取年度业绩数据（替换招募说明书中已过时的半年数据）
3. **最新季报** → 提取投资组合报告（1-11项）+ 累计净值图 + 最新季度业绩数据

使用 `curl -sL -o <filename>.pdf <url>` 下载。

### 第三步：提取数据

使用 `pdfplumber` 提取PDF文本：

```python
import pdfplumber, sys
sys.stdout.reconfigure(encoding='utf-8')

with pdfplumber.open('fund_prospectus.pdf') as doc:
    for i, pg in enumerate(doc.pages):
        text = pg.extract_text() or ''
        if '基金业绩' in text or '资产组合' in text:
            print(f'=== PAGE {i+1} ===')
            print(text)
```

**关键页面定位：**
- 招募说明书"九 基金业绩"：搜索"九 基金业绩"或"本报告期基金份额净值增长率"
- 招募说明书"八（九）基金的投资组合报告"：搜索"基金的投资组合报告"
- 季报投资组合报告：搜索"报告期末基金资产组合情况"
- 季报累计净值图：搜索"自基金合同生效以来基金累计净值增长率"

**图表提取（累计净值走势图）：**
```python
with pdfplumber.open('quarterly_report.pdf') as doc:
    pg = doc.pages[page_index]  # 找到包含图表的页
    for img in pg.images:
        # img坐标是PDF页面坐标（从顶部向下）
        scale = 200.0 / 72.0
        crop_left = int(img['x0'] * scale)
        crop_top = int(img['top'] * scale)
        crop_right = int(img['x1'] * scale)
        crop_bottom = int(img['bottom'] * scale)
```

渲染整页为图片后按坐标裁剪：
```python
im = pg.to_image(resolution=200)
im.save('page_full.png')
from PIL import Image
full = Image.open('page_full.png')
chart = full.crop((crop_left, crop_top, crop_right, crop_bottom))
chart.save('chart.png')
```

### 第四步：数据拼接规则

**九 基金业绩 年度表：**

| 数据来源 | 行 |
|---------|-----|
| 上次招募说明书原文 | 2020成立年 ~ 最近完整年度（保留原数据不动） |
| 最新年报 | 替换招募说明书中的"半年"行为全年数据 |
| 最新季报 | 新增"当年上半年"行 + 更新累计行 |

**数据源优先级：上次招募说明书原文 > 年报 > MCP东财**

MCP东财的年度业绩数据（尤其业绩比较基准）与招募说明书原文差异大，**不可直接使用**。仅在无法获取PDF原文时作为备选。

**校验：**
- 时间连续性：年度之间不能断开
- 复合验证：各年净值增长率连乘 ≈ 累计行"自基金合同生效起至今"

## 关键注意事项

1. **编号层级**：8.9是章节标识，下面直接跟"1、""2、""2.1、""9.1、"等，不要写成"8.9.1""8.9.2"
2. **数据源优先级**：上次招募说明书原文 > 年报PDF > MCP东财数据。MCP年度业绩数据（尤其业绩比较基准）与原文差异大，不可直接使用
3. **年度标准差**：必须从年报/招募说明书PDF提取，MCP可能不准确
4. **图表坐标**：pdfplumber的images列表坐标(top/bottom)是PDF页面坐标（从页面顶部向下），to_image渲染后用scale=resolution/72直接乘即可得到像素坐标，无需y翻转
5. **输出顺序**：先8.9投资组合报告，再9基金业绩（与招募说明书目录一致）
6. **表格格式**：使用markdown表格，表格前标注"金额单位：人民币元"
7. **文字内容**：11.1处罚说明、11.2备选股票库等文字内容原文照录，不要改写
