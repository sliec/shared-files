# A股每日全市场扫描

## 触发条件

用户说"扫描市场"、"扫面"、"今天行情怎么样"、"看看盘面"等意图时触发。

## 执行流程

### Step 0: 确认时间

```bash
date
```

根据当前时间标注报告类型：
- 11:30前：**上午盘中**
- 11:30-13:00：**午间**
- 13:00-14:50：**下午盘中**
- 14:50后：**尾盘**

### Step 1: 查关联外盘（先行指标）

**先查外盘再查A股**，顺序不可颠倒。

| A股板块 | 看哪个外盘 | 工具 | 用法 |
|---------|-----------|------|------|
| 电子/半导体 | SOX(费城半导体) | `mx_us_finance_data` | 取最近5日日收益率 |
| 通信 | SOX(同日+滞后β=0.20) | `mx_us_finance_data` | 同上 |
| 汽车/电力设备 | KOSPI(韩国) | `mx_hk_finance_data` 或 `mx_comprehensive_finance_data` | 取最新收盘 |
| 有色金属/计算机 | 纳斯达克/SOX隔夜 | `mx_us_finance_data` | 隔夜涨跌×β系数 |
| 银行 | SOX反向(负相关-0.21) | `mx_us_finance_data` | SOX跌→银行可能涨 |
| 医药 | **不看美股** | — | 只看国内政策和板块自身 |

**β系数速查**：
- SOX→电子: β=0.31(同日) + 0.13(滞后)
- SOX→通信: β=0.32(同日) + 0.20(滞后)
- NASDAQ→有色: β=0.22(滞后)
- NASDAQ→计算机: β=0.17(滞后)
- S&P500→汽车: β=0.35(滞后)

**预测公式**：外盘涨跌% × β = A股板块预期涨跌%

### Step 2: 拉取A股数据

**板块数据**（申万31一级行业）：

工具：`mcp__mx-ds-mcp__mx_index_block_finance_data`

需要字段：涨跌幅、超大单净流入、成交额、量比、上涨家数、下跌家数

**指数数据**：

工具：`mcp__tdx__get_index_overview` 或 `mcp__tdx__stock_quotes`

指数列表：
- 上证指数 (market=1, code=999999)
- 深证成指 (market=0, code=399001)
- 创业板指 (market=0, code=399006)
- 科创50 (market=1, code=000688)

### Step 3: 量价四象限分析

按涨跌幅正负 × 超大单正负，将31板块分为四象限：

| 象限 | 含义 | 操作指引 |
|------|------|---------|
| 涨+超大单正 | 主力做多 | 关注但勿追涨（一日游风险） |
| 涨+超大单负 | 散户抬轿主力撤 | 警惕一日游 |
| 跌+超大单正 | 主力逢低建仓 | 潜在底部信号 |
| 跌+超大单负 | 主力出货 | 回避 |

### Step 4: 一日游验证

对比昨天涨幅前列板块今天是否回落。

**判断标准**：昨天涨幅TOP5中，如果3个以上今天翻负或大幅回落，确认一日游模式有效。

一日游模式下：
- 不追涨今天强势板块
- 耐心等轮动到持仓板块
- 买入时机选尾盘而非早盘

### Step 5: 四维输出

**维度一：涨的还能不能继续涨？**

分析今日涨幅前列板块：
- 超大单是否持续为正？
- 量比是否>1（放量）？
- 是否连续多天强势（突破一日游）？
- 结论：可继续持有 / 一日游勿追

**维度二：跌的能抄底还是该割肉？**

分析今日跌幅前列板块：
- 超大单是否为正（主力逢低建仓）→ 可考虑抄底
- 超大单是否大幅为负（主力出货）→ 不抄底
- 是否连续多天下跌且超大单负 → 趋势性下跌，回避

**维度三：已买的怎么操作？**

逐只持仓诊断，每只须包含：
1. 今日所属板块涨跌幅 + 超大单
2. 与上次快照对比的变化方向（恶化/改善）
3. 外盘信号对该持仓的影响
4. 7天惩罚期状态（买入日期 + 是否已过7天）
5. 操作建议：持有 / 减仓 / 止损 / 补仓

**7天惩罚期规则**：C类基金持有<7天赎回扣1.5%。
- 须从用户持仓记录中获取买入日期
- 如不确定买入日期，主动询问用户
- 7天为日历日非交易日

**维度四：没买的哪些有机会？**

按信号强度排序，输出TOP5潜在机会板块：
- 涨幅适中 + 超大单持续为正 + 量比接近1
- 给出对应场外基金建议（如有）
- 标注一日游风险提示

### Step 6: 生成报告

报告格式参见 [report-template.md](report-template.md)

**文件命名**：`A股全市场扫描_YYYYMMDD_时段.md`
- 时段：盘中/午间/尾盘

**输出**：
1. Markdown报告文件（保存到outputs目录）
2. Widget展示（多tab交互）
3. 口头摘要（直接告诉用户关键发现）

## Widget设计规范

Widget使用4个tab：
1. **外盘信号**：海外指数+预测对照表
2. **31板块**：全量数据表，绿涨红跌，超大单颜色区分正负
3. **持仓诊断**：每只持仓一个card，含收益率/超大单/操作建议
4. **核心发现**：3-5个box，红=风险/绿=机会/黄=关注

CSS使用var(--bg-primary)等主题变量，兼容暗色/亮色。

## 多快照对比

如果同一天多次扫描，保留所有快照数据并在报告中做趋势对比：

```
| 板块 | 10:45 | 11:25 | 14:55 | 趋势 |
```

关注方向：
- 超大单恶化（正→负或负值扩大）
- 超大单改善（负→正或正值扩大）
- 涨跌幅方向变化（翻红/翻绿）

## 趋势确认标准

判断板块是否形成趋势（非一日游）：
- 连续4天超大单为正
- 周度数据翻正
- 第5天超大单不翻负

2-3天仅算反弹初期，不确认趋势。

## 用户持仓

持仓信息存储在USER.md的"投资偏好与约束"中。每次扫描前读取最新持仓列表。

调仓前必须确认：
1. 买入日期（确认7天惩罚期）
2. 当前收益率（判断止损/止盈）
3. 超大单趋势（判断资金方向）

## 关键陷阱提醒

1. **不要在13:00买入**（用户规则）
2. **卖出选11:30前**（用户规则）
3. **一日游模式下不追涨**
4. **外盘信号只作参考**：A股可能走出独立行情
5. **放量出货**：量比>1+超大单大幅为负 = 主力借放量出货
6. **缩量微涨**：量比<0.8+涨幅<1% = 缺乏持续性
