# 高德打车发票检查与下载

## 触发场景
用户说类似以下内容时触发：
- "查下高德发票"
- "邮箱有没有收到发票"
- "帮我看看发票到了没"
- "下载高德发票"
- "发票情况怎么样"

## 执行步骤

### 1. 运行发票下载脚本
```bash
python "D:\python\trae\program\2 保留场\直接运行\以此为准\1 高德发票下载.py"
```

### 2. 解析输出
脚本会输出一行关键信息，格式为：
```
处理情况: 找到X封邮件，下载X个文件，总金额XXX.XX元
处理完成，总金额 XXX.XX元
```
或
```
总金额 XXX.XX元 不在指定范围 (695-750元) 内，跳过复制
```
或
```
符合金额条件的文件已复制到指定目录
```

### 3. 向用户汇报
用自然语言汇报结果，包含：
- 找到几封发票邮件
- 下载了几个PDF附件
- 本次累计总金额
- 是否已复制到报销目录（R:\产品清核中心\固定交通费发票收集）

### 4. 异常处理
- 如果出现 `IMAP登录失败`，提示用户检查邮箱密码是否变更
- 如果出现其他错误，把错误信息告诉用户
- 如果找到0封邮件，告诉用户"最近没有新的高德发票邮件"

## 关键路径
- 脚本路径：`D:\python\trae\program\2 保留场\直接运行\以此为准\1 高德发票下载.py`
- 临时保存：`Z:\9 自动化专用\1 发票\`
- 报销归档：`R:\产品清核中心\固定交通费发票收集{年月}\`
- 金额区间：695-750元时自动归档到报销目录
