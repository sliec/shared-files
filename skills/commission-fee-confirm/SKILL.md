# 佣金与两费确认生成器

## 项目位置

本机安装路径：`D:\python\trae\program\1 个人项目\佣金两费确认工具\`

若该路径不存在（换机/新环境），从本 skill 目录的 `project\` 子目录复制整个文件夹到上述路径
（或任意本地目录），然后 `pip install -r requirements.txt`。**项目代码随 skill 自带，无需联网下载。**

## 使用场景与入口

用户提供社保/养老组合余额表（.xls，文件名如 `YL0802基本养老保险基金八零二组合余额表20260701至20260930.xls`、
`HZ1103大成基金管理有限公司-社保基金划转1103组合余额表….xls`），要求生成确认文件。

### 方式一：AI 会话直接跑 CLI（推荐，最快）

```
cd "D:\python\trae\program\1 个人项目\佣金两费确认工具"
python cli.py <余额表1.xls> <余额表2.xls> ... [--prev 上季佣金明细.xlsx] [--out 输出目录(默认桌面)]
```

### 方式二：Web 界面

```
python app.py   # http://127.0.0.1:5274，拖拽上传，页面下载
```

## 数据口径（必须遵守，勿自行更改）

| 项目 | 规则 |
|---|---|
| 托管费/基础管理费 | 余额表 2206/2207 科目「本期贷方发生额」（当季计提额） |
| 应付佣金 | 2209.01 下 3 级券商子科目「期末余额」，**只展示本季 ≠0 的券商** |
| 席位号 | 从上季佣金明细 .xlsx（sheet 名=组合代码）匹配券商带出；不提供则留空 |
| 实际支付管理费/风险准备金/管理人账户 | 公式：=基础管理费+调整 / =实际支付×20% / =实际支付−风险准备金 |
| 无佣金组合 | 佣金 sheet 只留表头占位，不省略 sheet |
| 输出命名 | `{组合名}-{YYYY年N季度}佣金与两费确认.xlsx`，默认存桌面 |

组合名/类型/期间全部从余额表标题行（第3行）自动解析：`HZ`前缀→"社保划转基金…确认函"，
`YL`前缀→"基本养老保险基金…确认函"。

## 步骤

1. 确认余额表文件存在（用户可能给 Z: 盘路径或桌面路径）
2. 问用户是否提供上季佣金明细（席位号来源），没有就直接生成
3. 跑 CLI，检查输出：每组合应打印两费金额、佣金券商数与合计
4. **校验**：佣金合计必须等于余额表 2209.01 科目期末余额；两费与余额表 2206/2207 本期贷方一致
5. 把生成文件路径告诉用户（桌面或指定输出目录）

## Pitfalls

- 余额表列位是固定的：期初=c12、本期借=c15、本期贷=c18、期末=c28（0-based，本位币金额列）
- Excel COM 重算公式缓存必须传**绝对路径**，相对路径会报"找不到文件"且被静默跳过
- 无 Excel/pywin32 时文件仍有效，只是打开后才计算公式
- 佣金只取 3 级券商科目；15011 这类只有 1 级合计的组合不填佣金明细（留占位）
- 上季明细 sheet 名与余额表代码的前导零可能不一致（"802" vs "0802"），匹配时去前导零
