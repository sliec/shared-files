# 佣金与两费确认生成器

上传社保/养老组合余额表（.xls），自动生成每组合一份「组合名-YYYY年N季度佣金与两费确认.xlsx」，
含两个 sheet：**两费确认**（托管费/基础管理费确认函，含公式）+ **佣金明细**（券商/席位/应付佣金）。

纯本地运行，核心生成**不依赖任何 AI / API Key**。

## 使用方式

### 方式一：Web 界面（推荐）

```
python app.py
```

浏览器打开 http://127.0.0.1:5274 → 拖入余额表（可多份）→（可选）拖入上季佣金明细 .xlsx
→ 点「生成确认文件」→ 下载 / 到输出目录（默认桌面）取文件。

### 方式二：命令行

```
python cli.py 余额表1.xls 余额表2.xls ... [--prev 上季佣金明细.xlsx] [--out 输出目录]
```

## 数据口径

| 项目 | 取数规则 |
|---|---|
| 托管费/基础管理费 | 余额表 2206 / 2207 科目「本期贷方发生额」（当季计提） |
| 应付佣金 | 2209.01 下 3 级券商子科目「期末余额」，只展示本季 ≠0 的券商 |
| 席位号 | 从上季佣金明细中匹配券商带出（不传则留空） |
| 实际支付管理费 | 公式 =基础管理费+管理费调整 |
| 风险准备金 / 管理人账户 | 公式 =实际支付×20% / =实际支付−风险准备金 |

无佣金明细的组合（如 108/1103/15011 的某些季度）佣金 sheet 仅保留表头占位。

## 依赖

```
pip install -r requirements.txt
```

公式缓存值依赖本机 Excel 重算（pywin32）；无 Excel 时文件仍可正常打开，Excel 打开后自动计算。

## 设置

Web 界面右上角「设置」可配置：输出目录、API Key（硅基流动等 OpenAI 兼容，仅为后续 AI 辅助
功能预留，核心生成不使用）。配置存于 `config.json`。
