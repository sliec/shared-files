## 三大归因方法总览

| 方法 | 数据来源 | 优点 | 缺点 | 适用场景 |
|------|---------|------|------|---------|
| **财报法** | 中报/年报利润表 | 数据准确、结构化 | 低频（半年/年度） | 半年度/年度深度分析 |
| **净值法** | 日频净值数据 | 时效性强、数据可得 | 因子多重共线性 | 快速概览、日常跟踪 |
| **持仓法** | 季度持仓报告 | 细节丰富 | 信息披露有限 | 挖掘基金经理能力特征 |

**实操建议**：三种方法互为补充。"固收+"多资产分析推荐净值回归+财务报表拆解结合。

## 方法一：财报法（利润表拆解）

### 利润表拆解框架

```
总利润 = 利息收入 + 投资收益 + 公允价值变动收益 + 其他收入
```

- **利息收入**：债券票息、存款利息
- **投资收益**：买卖债券/股票价差、衍生品收益
- **公允价值变动**：持有债券/股票的未实现浮动盈亏
- **其他收入**：买入返售金融资产收入、手续费返还

### "固收+"的利润表细分

对"固收+"基金进一步拆分为：
- 债券利息收入
- 债券投资收益 + 债券公允价值变动（债券投资）
- 股票投资收益 + 股票公允价值变动（"+"部分）

通过分析各资产的收益贡献度，判断基金经理的风格偏好（偏固收 vs 偏权益增强）。

### 局限性

数据准确但难以反映风格影响，时效性差（仅半年报和年报）。

## 方法二：净值法（Campisi因子回归）

### Campisi五因子模型

| 因子 | 代表维度 | 含义 |
|------|---------|------|
| **久期因子** | 利率水平风险 | 无风险利率整体变动对债券价格的影响 |
| **利率曲线结构因子** | 期限结构风险 | 长短期利差变化（曲线斜率）的影响 |
| **信用利差因子** | 信用风险溢价 | 信用债相对国债利差变化的影响 |
| **违约因子** | 信用风险尾部 | 信用违约事件对组合的影响 |
| **可转债/权益因子** | 权益/期权风险 | 可转债或股票的权益属性收益 |

"固收+"基金还需加入股票市场因子（市场/规模/价值/成长/质量/动量），用FF因子模型拆分股票端的β与α。

### 模型拟合优度（实证数据）

| 基金类型 | 调整R² |
|---------|--------|
| 利率债基 | 72.9% |
| 信用债基 | 93.9% |
| "固收+"基金 | 64.1% |
| 全样本平均 | >60% |

### 择时能力拓展

对T-M模型进行拓展，可同时检验基金经理在**股票市场及债券市场**的择时能力。实证表明全市场固收类产品仅少数拥有市场择时能力。

详细公式见 [references/methodology.md](references/methodology.md)

## 方法三：持仓法（Campisi模型为核心）

### Campisi四效应模型（纯债归因核心）

```
总收益率 = 收入效应 + 国债效应 + 利差效应 + 择券效应
超额收益率 = 基金各效应 - 基准对应效应
```

| 效应 | 含义 | 说明 |
|------|------|------|
| **收入效应** | 持有债券的票息收入 | 债券面值×票息率，稳定收益来源 |
| **国债效应** | 无风险利率变动导致的价格变化 | 反映利率边际水平变化 |
| **利差效应** | 信用利差变动导致的价格变化 | 反映信用风险溢价变化 |
| **择券效应** | 基金经理优选个券的超越基准部分 | 残差项，体现选券能力 |

**分解步骤**：
1. 单只债券总收益率 = 票息收益率 + 无风险利率变化收益 + 信用利差变化收益
2. 基准组合归因：基准总收益 = 收入 + 国债 + 利差
3. 基金组合分解（择券效应 = 残差）
4. 超额收益 = 基金各效应 - 基准各效应

**经验发现**：
- 国债效应和利差效应是债券组合收益的核心价值
- 各部分影响力排序：国债效应 > 利差效应 > 票息效应 > 择券效应
- 收入效应是纯债基金总收益的主要稳定来源
- 不同基金收益差异主要源于择券效应

### Brinson归因（"固收+"多资产）

在"固收+"场景中，Brinson模型分别用于债券部分和股票部分的归因：
- **配置收益**：基准与组合在各大类资产上的权重差异
- **选券收益**：同类资产内的回报率差异
- **交互收益**：配置与选券的交叉影响

### 加权久期模型

结合Wargner-Tito收益分解和Brinson归因，通过久期加权评估基金经理的久期管理能力。

## 三层归因递进框架

```
第一层：资产配置层面
  将收益按大类拆解 → 纯债贡献 / 可转债贡献 / 股票贡献

第二层：资产内部归因
  纯债 → Campisi模型（收入/国债/利差/择券四效应）
  可转债 → 对标转债指数，拆分β与α
  股票 → 多因子模型（市场/规模/价值/动量等因子）

第三层：基金经理能力分析
  择时能力（T-M模型拓展）：股票择时 + 债券择时
  择券/选股能力
  久期管理能力
  信用风险管理能力
```

## 绩效评价指标

### 风险调整收益指标

| 指标 | 公式 | 固收特殊意义 |
|------|------|------------|
| 夏普比率 | (Rp-Rf)/σp | 单位总风险的超额回报 |
| **卡玛比率** | 年化收益/最大回撤 | 固收+核心指标，≥2为良好 |
| 信息比率 | (Rp-Rb)/TE | 主动管理能力 |
| 索提诺比率 | (Rp-Rf)/下行σ | 只考虑下行波动，适合稳健产品 |

### 风险指标

| 指标 | 定义 | 固收特殊意义 |
|------|------|------------|
| 最大回撤 | 净值最大跌幅 | 固收核心风险指标 |
| 年化波动率 | 收益率年化标准差 | 整体波动水平 |
| **久期** | 组合加权久期 | 利率风险暴露 |
| **杠杆率** | 总资产/净资产 | 杠杆使用程度 |

### 持有期体验指标

- **创新高能力**：创新高天数占比
- **涨跌收益比**：上涨日均涨幅 / 下跌日均跌幅
- **季度/月度胜率**：正收益期间占比

## 基金经理能力评估

| 管理维度 | 评估要点 |
|---------|---------|
| **久期管理** | 对利率走势预判的准确度，主动调整久期的时机 |
| **信用风险** | 信用下沉（高票息）vs 违约风险的平衡 |
| **杠杆运用** | 控制流动性和融资成本前提下增厚收益 |
| **组合分散** | 行业集中度适度分散，风险调整后收益更好 |
| **流动性管理** | 债市波动或大额赎回情景下的应对能力 |
| **择时能力** | 股票择时 + 债券择时（仅少数固收产品具备） |

## "固收+"基金优选框架

```
第1步：历史业绩筛选
  累计收益率 / 夏普比率 / 最大回撤

第2步：业绩归因筛选
  资产配置能力 / 权益投资能力 / 普通债券投资能力 / 可转债投资能力

第3步：综合评估
  综合归因表现 → 构建优选组合
```

## 报告撰写模式

### 报告结构（七部分）

```
摘要 + 数据说明

一、业绩总览（区间收益、基准对比、最大回撤）
二、财报法归因（利润表拆解，各资产收益贡献度）
三、净值法归因（Campisi五因子回归，因子暴露与Alpha）
四、持仓法归因（Campisi四效应 + Brinson多资产配置）
五、绩效指标全景（风险调整收益 + 风险指标 + 持有期体验）
六、基金经理能力画像（久期/信用/杠杆/分散/择时）
七、综合结论与投资建议
```

### 撰写规范

- 论述文体，不用Q&A格式
- 数据标注来源和时间区间
- 结论须量化支撑
- 跨类型不可直接对比（固收 vs 权益的卡玛/夏普不可比）
- 同类基金间比较才有意义

## 注意事项

- **因子多重共线性**：净值法回归中因子相关性较强，需谨慎处理
- **信息披露限制**：持仓数据季度披露且有时滞
- **基准选择**：Campisi模型高度依赖比较基准，需选用合适的债券指数
- **久期估计**：基于净值估算组合久期存在近似误差
- **市场变化风险**：归因模型基于历史经验，市场变化可能导致模型失效
- **跨类型不可比**：卡玛/夏普等指标只在同类基金间比较有意义
