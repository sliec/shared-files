# 固收类基金归因方法论详细参考

## Campisi模型（债券业绩归因核心）

### 模型概述

Campisi模型由Stephen Campisi提出，专门用于纯债型基金业绩归因分析。该模型考虑了债券的特征和特殊风险，将债券收益分解为逻辑清晰的四个部分。

### 收益分解公式

**单只债券收益率分解**：

$$R_i = \underbrace{\frac{C_i}{P_{i,0}}}_{\text{票息收益}} + \underbrace{-D_{mod} \times \Delta y_{rf}}_{\text{无风险利率变化}} + \underbrace{-D_{mod} \times \Delta spread}_{\text{信用利差变化}}$$

其中：
- $C_i$ 为期间票息收入
- $P_{i,0}$ 为期初价格
- $D_{mod}$ 为修正久期
- $\Delta y_{rf}$ 为无风险利率变动
- $\Delta spread$ 为信用利差变动

**组合层面四效应分解**：

| 效应 | 公式 | 经济含义 |
|------|------|---------|
| 收入效应 | $IE = \sum w_i \times \frac{C_i}{P_{i,0}}$ | 组合加权票息收益 |
| 国债效应 | $TE = \sum w_i \times (-D_{mod,i}) \times \Delta y_{rf}$ | 利率水平变动影响 |
| 利差效应 | $SE = \sum w_i \times (-D_{mod,i}) \times \Delta spread_i$ | 信用利差变动影响 |
| 择券效应 | $AE = R_p - IE - TE - SE$ | 残差，个券选择能力 |

**超额收益归因**：

$$ER = (IE_p - IE_b) + (TE_p - TE_b) + (SE_p - SE_b) + (AE_p - AE_b)$$

### 经验发现

- 各部分收益影响力排序：国债效应 > 利差效应 > 票息效应 > 择券效应
- 国债效应和利差效应是债券组合收益的核心价值来源
- 表现优异的基金通常在国债效应和利差效应上获得显著Alpha
- 收入效应是纯债基金总收益的主要稳定来源
- 不同基金收益差异主要源于择券效应

## 净值法：Campisi五因子回归

### 模型设定

$$R_p - R_f = \alpha + \beta_1 F_{duration} + \beta_2 F_{curve} + \beta_3 F_{credit} + \beta_4 F_{default} + \beta_5 F_{equity} + \epsilon$$

### 因子构建明细

| 因子 | 构建方式 | 数据来源 |
|------|---------|---------|
| 久期因子 $F_{duration}$ | 国债收益率曲线水平因子变化 | 中债国债收益率曲线 |
| 利率曲线因子 $F_{curve}$ | 10Y-1Y国债期限利差变化 | 中债国债收益率曲线 |
| 信用利差因子 $F_{credit}$ | AA+级信用利差指数变化 | 中债信用利差指数 |
| 违约因子 $F_{default}$ | 高收益债利差变化 / 评级利差 | 高收益债指数 |
| 权益因子 $F_{equity}$ | 中证转债指数 / 沪深300收益率 | Wind/聚宽 |

### "固收+"拓展因子

对于"固收+"基金，股票部分需额外引入：

| 因子 | 来源 |
|------|------|
| 市场因子(Rm-Rf) | 沪深300超额收益 |
| 规模因子(SMB) | 小市值 - 大市值组合 |
| 价值因子(HML) | 高BP - 低BP组合 |
| 动量因子(MOM) | 过去12月赢家 - 输家 |

### 模型拟合优度（2025年1月-8月实证）

| 基金类型 | 调整R² | 最显著因子 |
|---------|--------|----------|
| 利率债基 | 72.9% | 久期、利率曲线 |
| 信用债基 | 93.9% | 久期、信用利差 |
| "固收+"基金 | 64.1% | 久期、权益因子 |
| 全样本平均 | >60% | — |

### 多重共线性处理

净值法的主要缺陷是因子之间存在较强相关性：
- 久期因子与利率曲线因子常高度相关
- 信用利差因子与违约因子存在共线性

处理方法：
1. VIF检验（方差膨胀因子），VIF>10时剔除或合并因子
2. 主成分分析(PCA)降维
3. 逐步回归筛选
4. Lasso正则化

## 择时能力检验（T-M模型拓展）

### 单市场择时（股票或债券）

$$R_p - R_f = \alpha + \beta_1(R_m - R_f) + \beta_2(R_m - R_f)^2 + \epsilon$$

- β₂ > 0 且显著 → 具备该市场的择时能力

### 双市场择时（股票+债券）

$$R_p - R_f = \alpha + \beta_1(R_{stock} - R_f) + \beta_2(R_{bond} - R_f) + \gamma_1(R_{stock} - R_f)^2 + \gamma_2(R_{bond} - R_f)^2 + \epsilon$$

- γ₁ > 0 → 股票市场择时能力
- γ₂ > 0 → 债券市场择时能力

实证表明全市场固收类产品仅少数拥有市场择时能力。

## Brinson归因（"固收+"多资产）

### 在固收基金中的应用

对于"固收+"基金，Brinson模型按资产大类分解：

| 资产类别 | 配置效应 | 选券效应 |
|---------|---------|---------|
| 利率债 | 权重偏离贡献 | 利率债内个券选择 |
| 信用债 | 权重偏离贡献 | 信用债内个券选择 |
| 可转债 | 权重偏离贡献 | 转债内个券选择 |
| 股票 | 权重偏离贡献 | 股票内个股选择 |

### 加权久期模型

结合Wargner-Tito收益分解和Brinson归因：
$$\Delta R_{duration} = -D_{mod}^{active} \times \Delta y$$

其中 $D_{mod}^{active} = D_{mod}^{portfolio} - D_{mod}^{benchmark}$，衡量基金经理主动久期偏离的贡献。

## 中金五因子风险模型

中金公司搭建的风险因子模型适用于固收类基金：

| 因子 | 维度 | 衡量内容 |
|------|------|---------|
| 久期因子 | 利率水平风险 | 利率整体水平变动 |
| 期限结构因子 | 收益率曲线形态 | 曲线斜率/凸度变化 |
| 信用因子 | 信用风险溢价 | 信用等级利差 |
| 违约因子 | 尾部信用风险 | 违约事件冲击 |
| 权益因子 | 股票/可转债权益属性 | 权益市场波动 |

实证检验显示该模型对固收类基金有较优的解释力。

## 绩效评价详细指标

### 卡玛比率与夏普比率的区别

| 维度 | 卡玛比率 | 夏普比率 |
|------|---------|---------|
| 风险度量 | 最大回撤（下行） | 波动率（总风险） |
| 关注点 | 最痛体验 | 整体波动 |
| 固收适用性 | 更贴合（固收回撤小） | 通用 |
| 良好标准 | ≥2（"固收+"） | ≥1 |

### 固收特有指标

| 指标 | 定义 | 评价标准 |
|------|------|---------|
| 久期 | 组合加权修正久期 | 反映利率敏感性 |
| 杠杆率 | 总资产/净资产 | 100-140%为常见范围 |
| 信用下沉度 | 低评级债券占比 | 越高收益越高但风险越大 |
| 持有期创新高占比 | 创新高天数/总天数 | >60%为优秀 |
| 季度胜率 | 正收益季度/总季度 | >70%为稳健 |

## 回归执行注意事项

### 滚动窗口选择

| 窗口 | 适用场景 |
|------|---------|
| 60个交易日 | 捕捉近期风格变化（约3个月） |
| 120个交易日 | 平衡稳定性与及时性（约半年） |
| 250个交易日 | 长期风格特征分析（约1年） |

### 基准选择要点

Campisi模型等持仓法高度依赖基准：
- 利率债基 → 中债国债总财富指数
- 信用债基 → 中债信用债总财富指数
- "固收+"基金 → 复合基准（如中债综合×80%+沪深300×20%）
- 可转债基金 → 中证转债指数

### 统计显著性标准

| p值 | 显著性水平 | 含义 |
|-----|----------|------|
| < 0.01 | 高度显著 | 99%置信度 |
| < 0.05 | 显著 | 95%置信度 |
| < 0.10 | 边缘显著 | 90%置信度 |
| ≥ 0.10 | 不显著 | 不能排除随机性 |
