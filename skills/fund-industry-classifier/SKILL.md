# 基金实际行业归属判定

## 核心理念

**不看名字、不看跟踪标的，只看持仓。** 基金名字可能误导（如"核心成长"实际全仓锂矿），跟踪标的可能失真（如声称跟踪中证500但持仓100%偏离）。唯有持仓反映基金经理的真实押注。

## 执行流程

### Step 1: 拉取持仓数据

工具：`mcp__mx-ds-mcp__mx_fund_finance_data`

查询语句模板：
```
{基金代码} 最新一期前十大重仓股名称、持股数量、持股市值、占净值比
```

同时拉取上一期持仓（用于时序漂移检测）：
```
{基金代码} 前十大重仓股名称（上一期报告）
```

**数据质量检查**：
- 前十大合计占净值比 < 40% → 标记 `coverage_flag = "partial"`，置信度降一级
- 最新报告距今 > 6个月 → 标记 `data_expired = true`

### Step 2: 行业+概念双层映射

对每只持仓股票，赋予两层标签：

**第一层：申万一级行业**（31个，互斥）

优先使用MCP工具查询：
```
{股票代码} 所属申万行业
```

若工具不可用，使用下方内置标签库（`stock_tag_library`）。

**第二层：概念主题标签**（可多选）

从内置标签库查询。标签库覆盖用户关注的核心主题：
- 锂矿/锂电/新能源上游
- 机器人/智能制造
- 半导体/芯片
- 银行/金融
- 医药/医疗
- 新能源车/汽车
- 煤炭/资源品
- 券商/非银
- 军工/国防
- 消费/食品饮料
- 光伏/新能源
- AI/人工智能/算力
- 房地产/基建

**标签库查询优先级**：
1. 本技能附带的 `stock_tag_library` 数据（覆盖~200只核心股票）
2. MCP工具 `mcp__mx-ds-mcp__mx_ashare_finance_data` 查询个股所属行业
3. 基于股票名称关键词的兜底映射

### Step 3: 聚合计算

**行业暴露度**（申万一级口径）：
```
行业暴露度(i) = Σ 持仓权重(j) × I(股票j ∈ 行业i)
```

**概念暴露度**（可超过100%）：
```
概念暴露度(k) = Σ 持仓权重(j) × I(股票j 有概念k标签)
```

**集中度指标**：
- 最大单一行业暴露度 = max(行业暴露度_i)
- CR3 = 前3大行业暴露度之和
- HHI = Σ (行业暴露度_i)²

**持仓不完整修正**：若仅前十大（合计占比X%），将暴露度等比放大至100%。

### Step 4: 分类判定（按优先级顺序执行）

**规则1：纯主题基金**
满足任一：
- (a) 最大单一概念暴露度 ≥ 80%
- (b) 最大单一行业暴露度 ≥ 80%（申万二级口径）
- (c) 前5大重仓中 ≥ 4只属于同一概念，且合计权重 ≥ 70%

→ 输出：`纯主题基金（{概念名}）`

**规则2：行业聚焦基金**
同时满足：
- (a) 最大单一行业暴露度 ≥ 50%（申万一级）
- (b) CR3 < 85%
- (c) 不满足纯主题条件

→ 输出：`行业聚焦基金（{行业名}）`

**规则3：混合基金**
满足任一：
- (a) 最大单一行业暴露度 < 50%，且 HHI < 2500
- (b) CR3 在 50%~85%，且最大单一行业 < 50%

→ 输出：`混合基金（{Top3行业}）`

**规则4：宽基基金**
同时满足：
- (a) 最大单一行业暴露度 < 20%
- (b) HHI < 1500

→ 输出：`宽基基金`

### Step 5: 风格漂移检测

**维度1：名称漂移**
提取基金名称中的行业关键词 → 映射到概念
比较：名称隐含行业 vs 实际最大概念暴露度
偏离度 > 40% → 触发"名称漂移"警报

**维度2：基准漂移**
比较：基金实际行业分布 vs 业绩比较基准行业分布
最大基准偏离 > 30% → 触发"基准漂移"警报

**维度3：时序漂移**
比较：本期行业暴露度 vs 上期行业暴露度
若上期与本期最大行业不同 → 触发"时序漂移"警报

**漂移等级**：
| 等级 | 偏离度 |
|------|--------|
| 无漂移 | < 20% |
| 轻度漂移 | 20%~40% |
| 中度漂移 | 40%~60% |
| 严重漂移 | > 60% |

**伪宽基识别**：
同时满足：(a) 声称跟踪宽基指数 (b) 实际最大行业暴露度 > 40%
→ 标记为"伪宽基 — 实际为{行业}主题基金"

## 阈值设计理由

| 阈值 | 取值 | 理由 |
|------|------|------|
| 纯主题下限 | 80% | 容忍20%现金/打新/调仓缓冲 |
| 行业聚焦下限 | 50% | 过半仓位集中一个行业 = "押注" |
| 宽基上限 | 20% | 超过20%说明有行业偏离 |
| HHI 2500 | 高集中度 | 参考反垄断HHI阈值 |
| CR3 的 85% | 分散度边界 | 超过85% = 3个以内主题 |

## 置信度扣分项

| 因素 | 扣分 |
|------|------|
| 仅有前十大持仓 | -0.10 |
| 持仓覆盖率 < 60% | -0.15 |
| 报告距今 > 3个月 | -0.05 |
| 报告距今 > 6个月 | -0.20 |
| 行业映射失败率 > 10% | -0.10 |

## 边界Case处理

| Case | 策略 |
|------|------|
| 50%新能源+50%AI | 判"混合"，附加"双主题聚焦" |
| 名字写"成长"但全仓锂矿 | 分类基于持仓，触发"名称漂移" |
| 跟踪中证500但持仓全偏 | 分类基于持仓，标记"伪宽基" |
| 行业指数基金 | 直接归入"纯主题"，不走判定 |
| QDII/海外基金 | 行业映射到GICS，概念标签扩展 |
| 货基/债基 | 不适用，直接排除 |
| 新基金（< 2季度） | 标记"数据不足" |

## Pitfalls

1. **不要只看基金名字或跟踪标的**：这是本技能存在的核心原因。012710名为"华夏核心成长"跟踪中证500，实际100%锂矿。
2. **概念标签比行业分类更重要**：锂矿横跨"有色金属"+"化工"，单看申万一级会分散。概念标签"锂矿"才能准确归集。
3. **前十大持仓不完整**：等比放大到100%是近似，需标记置信度降低。
4. **基金经理可能跨期漂移**：同一基金不同季度持仓可能完全不同，必须做时序对比。
5. **港股持仓**：部分基金重仓港股（如012710曾持有赣锋锂业H股），需同时覆盖A+H标签。
